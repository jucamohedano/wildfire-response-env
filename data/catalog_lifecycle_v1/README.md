# Active exercises and archives

Prepared inputs and active development tasks can be [downloaded from Hugging Face](../../docs/hub-runtime.md)
without rebuilding map data. The release keeps all source-estimate and lifecycle guards.

Only the corrected **24-hour development exercises** are active. The versioned
[registry](registry.json) is generated by
`PYTHONPATH=envs/wildfire_response/core/src python -m wildfire_core.catalog_lifecycle`.
Its canonical hash pins lifecycle metadata, not physical validation.

- Known synthetic fixture pins select six coverage/egress cases.
- Known estimated-map/road pins select six real-map v2 cases.
- Unknown pin pairs have no implicit default or active suite.
- Twenty superseded day configurations and the four older catalogs are archived.
  Original files remain in place because recorded trajectories and source hashes
  reference their paths. Archiving removes them from active discovery and the
  recommended learning path; deleting them would destroy replay support.

The old night-only catalogs cannot acquire daytime aircraft coverage without a
new scenario/interface identity. Rather than multiply lightly corrected copies,
they are retired. Their existing 28 pre-ignition weather and four destination
redesign dispositions remain historical; none is promoted to day-mode training.
The original six day fixtures keep their ineffective inherited assignments for
regression, while corrected active cases have useful approaches or disclosed
recovery. Other superseded day variants remain available for comparisons.

## Use

Core `IncidentDayEnv.reset()` chooses the active case for its exact input/network
pins. Supplying an explicit legacy core ID still permits archival replay. The
OpenEnv/HTTP adapter is stricter: old IDs require constructor
`allow_archived_scenarios=True` or server `--allow-archived-scenarios`.
`GET /tasks` supplies context-specific choices and the viewer default; it does not
expose private curation or future events.

The historical AgentEnv exporter and benchmark learning CLI require
`--allow-archived-catalog` for data-producing/model commands. This acknowledgment
is separate from GPU budgets, API access, source rights and publication approval.
Read-only inspection and explicit replay remain available. An archive is not
silently rewritten, relabeled or rescored.

## Limits

There is currently **no active train/validation/test incident-day corpus**. These
are related development probes, not 12 independent incidents or expert labels.
The full-day runtime can exercise aircraft, ground access and relocation, but
field calibration, estimated fuel, source approval and metadata remain separate
issues. Do not treat lifecycle `active_development` as operational certification.
See #18, #34, #42 and #44.

[Measured remediation evidence](../../results/realism-remediation-20261029.html)
records current-code replays and aircraft cycles. The
[original audit](../../results/scenario-realism-review-20261029.html) remains
unchanged as the historical baseline.
