Audit and budget

  • Observed valid model operations: 3 resource requests, 3 readback confirmations, 3 authorizations and 2 triage assessments.
  • Seven protocol-invalid responses were penalized, not repaired into legal waiting actions.
  • The first request timeout was 90 seconds. A manual continuation used 180 seconds and exactly replayed the saved three-decision prefix before resuming. That continuation also timed out.
  • The prior $0.90496 conservative reservation was subtracted first; the continuation cap was $4.09504. Combined conservative estimate: $2.369192, including full reservations for both missing-usage calls.
  • Known usage: 86,823 prompt tokens and 3,792 completion tokens. Actual provider billing is not confirmed.
  • The API catalog price fields appeared 100× higher than the public webpage. The larger API-derived rates governed the conservative guard; no cache discounts were assumed.
  • No GPU rental, local model process, training run or automatic provider fallback was started. Evaluation workers and preview are stopped. The temporary key was not stored in repository or result files.
