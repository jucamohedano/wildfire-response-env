What is grounded, and what is assumed?

  • Source facts: detection clock, consistent first-ground-arrival interval and evaluator-only incident-size stratum.
  • Explicit assumptions: half the response interval becomes a bounded ground-transit component; a simple daylight clock and three wind profiles frame the exercise.
  • Still synthetic: common grid, five-unit fleet, population, phone/chat scripts, communication delays, fire spread and suppression effects.
  • Never forced: historical containment, extinction or burned area. Delaying dispatch changes actual simulated arrival.

The new behaviour: clarify an unlocated report

Request a location → wait for a simulated reply → receive an approximate claim → investigate with a resource → verify with sensor evidence. A reply is not a truth label.

Large exercises include a separate assumed front described initially only by an unlocated report. The baseline that asks for clarification can investigate that front.
