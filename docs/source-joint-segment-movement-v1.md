# Population segment movement seam v1

This private, opt-in seam revalidates an existing Operations population journey
against the exact paths and source identities of the unreviewed
[road-segment exercise](expanded-road-segment-exercise-v1.md). It is a building
block for a shared host, not a shared host, score, source episode, or a ground
work-site rule. The explicit low-confidence exercise assumption is that no
unmapped water crossing exists on the four listed directed segments; flood,
legal access, vehicle suitability and historical conditions remain unknown.
No cell is made walkable or generally accessible.

The trusted driver supplies an independent digest of the segment implementation
and must pin this seam's identity with all host and checkpoint identities.
The seam checks exact original case/group/destination path, canonical full-edge
geometry, mode and durations, the actual prior position, and the next swept
segment against current burning, wind and dynamic exclusions. An altered
journey, unsupported path, mid-edge origin or inconsistent clock fails closed.
The provided source candidate and plans contain private source geometry and
must not be sent to actors. This assumption does not approve any ground
resource route, return, work site, or a route to a different destination.

The focused regression uses the real pinned candidate and Operations with a
delayed evacuation, dynamic block, checkpoint restoration and resumed movement.
It does not exercise weather, fire spread, aircraft or a joint incident host.
