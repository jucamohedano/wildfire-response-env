# Publication gate

This repository is an implementation and evaluation candidate. Public hosting,
dataset upload and model publication are separate actions.

- A root code license has not been selected and approved. Do not assume that
  extraction from the hackathon repository grants a particular license.
- Confirm the rights and required notices for inherited code and source-derived
  geographic/fuel/weather artifacts before packaging them for redistribution.
- Keep provider credentials, private evaluator artifacts and raw operational
  records out of public uploads. A public-observation field is not itself a
  redistribution clearance.
- External imagery is display context; no upstream AirOps/PortSim code or visual
  assets were copied for this benchmark implementation.
- Qwen's pinned model metadata was checked separately; model licensing does not
  resolve this repository's code or source-data rights.

Until these checks are resolved by the owner, release preparation means cards,
reproducible private artifacts and draft PRs—not automatic publication.
